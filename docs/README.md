# docs

`frame-structure.svg` — the section layout of a generated handoff frame, used in the
top-level README.

To add a real render: run the skill on a component, select the handoff frame in Figma,
export at 2× as PNG, and save it here as `handoff-frame.png`. Crop to the first two
chapter groups — the full frame is roughly 1400 × 10000 and reads as a sliver at any
width GitHub will render.
